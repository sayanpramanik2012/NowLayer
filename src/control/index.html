Enable performance monitoring to start.

Game FPS · included

FPS capture is bundled with NowLayer. Turn on Performance from Home, then switch to your game. No extra download or executable path is needed. FPS measures application presents; displayed FPS and generated frames can differ.

Windows needs permission to collect ETW events. If access is denied, use an account in Windows' Performance Log Users group (sign out and back in afterward), or run NowLayer as administrator for capture. Toggle monitoring off and on to retry.

Temperatures & GPU support

NVIDIA readings use the driver’s nvidia-smi utility. For CPU temperature and AMD/Intel GPU sensors, run Libre Hardware Monitor with its WMI provider enabled and the required sensor permissions. Keep it running while playing. Missing or stale sensors show a dash on the overlay and “unavailable” here.

CPU and RAM work without extra tools. Monitoring pauses when the overlay is hidden. Use borderless-windowed games as with the media overlay.

HELP & DIAGNOSTICS

Know what is working.

Fast test checklist

  1. Start media: Play a song in Spotify, Chrome, Edge, Firefox, or VLC.
  2. Check metadata: Its title should appear on Home and on the overlay.
  3. Check safe input: While locked, click through the overlay into the app below it.
  4. Check interaction: Press Ctrl + Shift + L and use play/pause.
  5. Check video: Select an open YouTube window under Video PiP.
  6. Check a game: Start a borderless-windowed game and confirm the overlay remains visible.
